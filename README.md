# 🛡️ EdgeShield_AI

> An AI-powered on-device cybersecurity solution for real-time phishing, scam, and threat detection.

## Project Information

**Competition:** Bharat AI-SoC Challenge 2026-27  
**Problem Statement:** PS3 - Cybersecurity & Digital Safety  
**Challenge Theme:** On-device Threat, Phishing & Scam Detection

---

##  Overview

**EdgeShield_AI** is a privacy-preserving, edge-based cybersecurity system designed to detect phishing attempts, scams, malicious URLs, and other digital threats directly on user devices.

The solution leverages Artificial Intelligence and Machine Learning techniques to provide fast, secure, and reliable threat detection while minimizing dependency on cloud infrastructure. By performing inference at the edge, the system reduces latency, improves privacy, and enhances user trust.

This repository contains the complete project implementation, architecture, experimental analysis, evaluation results, and technical documentation prepared for the **Bharat AI-SoC Challenge 2026-27**.
